I tried Astra as a coding model and used it to build PromptShelf, a small desktop app for saving and reusing AI prompts. You fill in the template fields yourself, then copy the prompt into your preferred AI tool. Everything stays on your computer.

If you'd like to try it: https://github.com/ravikadam/promptshelf

The README has the download link and instructions. If Apple or Windows blocks it, please read the “If your computer blocks the app” section; it also has Linux installation help.

Would appreciate any feedback on whether it's useful or anything that doesn't work as expected.
